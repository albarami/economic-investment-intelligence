# contracts/ — source contracts and the release contract

This folder will hold the source contracts and the release contract: JSON Schema files with a semantics note for each contract.

## Rules

- Record types keep their neutral contract names: `business_register.v1`, `employment.v1`, `wages.v1`, `residence.v1` and `mobility.v1`. No custodian is named.
- No real custodian field name, file name, record or count is ever written here.
