## Context

The approved S6-T34 plan and lead ruling L-974 permit offline part-one work.
L-974(a) supplies installed pins and retreats; L-974(b) permits local package
reading while publisher-page reading stays a lead open item. L-974(d) blocks C5
until the shared S3 Fact chip family merges, forbids a second family, leaves
phone capture to the owner and laptop capture to owner handoff, and requires
unprovided fixture cardinalities to remain proposals. L-974(e) assigns this
proposed record number, subject to confirmation at merge.

## Proposed disposition

Retain ECharts as the designated baseline under decision 0042 item 9. No library
receives an adoption or native-performance pass. Plot and visx remain off-path
spike dependencies. The existing product and S1 performance contracts are unchanged.

## Evidence and acceptance

Sources are `web/spikes/charts/contract.json`, the invented renderer fixture,
`web/spikes/charts/evidence/bundle.json`, the spike test sources and the command
exits recorded under PROGRESS.md heading "S6-T34 — Chart spike part one".
Bundle output records gzip/Brotli bytes and source/fixture/contract/lock hashes.
It measures export-preserving adapter entry output, not integrated product costs.
No device parse, presented-render latency, native frame rate or heap result was
measured. No build-byte cutoff is invented.

For each of ECharts, Observable Plot and visx:

- C1 BLOCKED: shared closed fixture workloads and budget contract exist, but
  cardinalities and measurement instrumentation need pre-run confirmation;
  the uncommitted worker changes cannot supply the plan's committed hash seal.
- C2 BLOCKED: offline emitted-byte measurements exist; native parse attribution
  and full-story memory measurements are absent.
- C3 BLOCKED: native laptop and phone capture matrix is absent. The loopback page
  shows a blocked message, and the recorder refuses collection.
- C4 BLOCKED: invented timing controls prove policy boundaries only, not native
  performance. The S1 orbit and full-story memory gate remain separate.
- C5 BLOCKED under L-974(d): the shared Fact chip family is absent. Descriptor
  tests are not DOM, accessible-table, actual-lineage or chip acceptance.
- C6 BLOCKED as a complete acceptance row: each implemented policy guard has
  invented positive/negative controls, but actual DOM/chip enforcement and qualified native collector
  integration remain unavailable. Offline matrix digest/completeness controls
  pass only invented validator controls. A passing unit suite earns no broader pass.
- C7 PASS for this part-one disposition: blocked results are explicit and the
  baseline is retained. Independent another-maker review remains pending.

## Consequences and next evidence

The spike page mounts no numerical chart. Adapters are measured offline only.
No new Fact family, model call, network test, origin decal or production import
is introduced. The native verifier deliberately has no accepting path; neither
self-reported native metadata nor headless timings can become native evidence.

Before continuing: confirm fixture sizes, native paint/parse/heap attribution,
phone OS/browser and local transport; merge the S3 Fact family; implement actual
DOM governance and digest-bound native capture with complete matrix validation;
collect all runs; obtain the lead's official web-page reading and another-maker
review. Adoption can change only after the full evidence contract passes.
